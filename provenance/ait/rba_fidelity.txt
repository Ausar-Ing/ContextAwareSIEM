Table 4a (per-module AUROC, default parametrization: triangle windows, centred, normalizers from the whole file).
Data: the AIT-ADS russellmitchell files shipped with their CATS implementation (commit 628cf48,
datasets/ait_wazuh.zip: 23,116 alerts, 7,661 positive; datasets/ait_suricata.zip: 9,186 alerts, 44 positive).
Positives: CATS's `misuse` flag. Grouping: hostname (Wazuh) / source IP (Suricata) for accumulation and variety,
alert type for rarity and aperiodicity. CATS's code was not executed; tools/rba.py was run with centred=True
(an option added for this check only; the evaluation's trailing-window output is unchanged, verified identical,
max abs difference 0.0 over 22 variants).

Result: with the paper's setting (column ours-ctr-tri), 23 of 26 published values are reproduced exactly at two
decimals and the other 3 differ by 0.01 (max raw difference 0.014: Suricata aperiodicity_1m; also Suricata
accumulation_1d and Wazuh aperiodicity_1m). Known approximations: aperiodicity normalized on a 2000-alert sample
(CATS uses all alerts) and no clipping of windows at the file edges.
The trailing windows used by our evaluation (ours-past-tri) are shown for reference; they differ from the
published centred values, mainly on Suricata variety and on the 1-day windows, as expected.
